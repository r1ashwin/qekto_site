Quickstart

Five minutes to your first request

Pilot customers receive the Qekto distribution from the founders. With it, you can go from an empty host to proxied production traffic like this.

1 · Run Qekto

cp .env.example .env
python3 -c "import secrets; print('QEKTO_SECRET_KEY=' + secrets.token_urlsafe(48))" >> .env
docker compose up -d
docker compose logs qekto | grep "setup token"

One container and one volume. Liveness at /healthz, readiness at /readyz. For local evaluation without Docker, run uv sync && QEKTO_ENV=development uv run qekto serve.

2 · Set up your organization

Open https://your-host/setup, enter the bootstrap token, and create the owner account. Then create a project. Onboarding asks what your product does with AI, which modalities you expect, your latency and cost goals, your success criteria, what ground truth you have, and whether upstream outputs may legally be used for training.

3 · Connect your provider

Under Settings → Add upstream, enter your provider's OpenAI-compatible base URL and API key. The key is encrypted and never shown again. Click Test: the upstream receives traffic only after the connection test passes.

4 · Create a key and switch your client

import os
from openai import OpenAI

client = OpenAI(base_url="https://your-host/v1", api_key=os.environ["QEKTO_API_KEY"])
resp = client.chat.completions.create(
    model="gpt-4o-mini",
    messages=[{"role": "user", "content": "Hello"}],
    extra_headers={"X-Qekto-Workload": "ticket-triage"},  # optional explicit workload name
)

Your request goes out unchanged and the provider's response comes back unchanged. Each response carries x-qekto-request-id.

5 · Add ground truth and graduate

Label captured requests from your backend with a labels:write key:

curl https://your-host/v1/qekto/labels \
  -H "Authorization: Bearer $QEKTO_LABELS_KEY" -H "Content-Type: application/json" \
  -d '{"request_id": "req_…", "expected": "billing"}'

On the workload page, set the contract (task family, output schema, evaluator, training rights). The readiness panel lists anything that still blocks graduation. When nothing is missing, click Train & evaluate, review the release card, and roll out with shadow → canary → full.
